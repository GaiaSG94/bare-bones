# Bare Bones

> Drop a spreadsheet. Share an *explorer*.

A copyable skeleton for in-browser data explorers. Drop a CSV, get a typed
table, filters, charts, and a `#bb=` link that reopens the exact same view.
No server, no database, no account.

**Two apps, one skeleton** (Kiroween 2026 — Skeleton Crew):

- `apps/nonprofit-budget` — Fern Street Budget (Orb design)
- `apps/club-results` — Riverside Six (Floodlight design)

## Status

This repository is being built step by step. See `docs/` for the frozen
public API contracts and `tools/` for budget and guard checks.

## Install

```sh
pnpm i
pnpm dev
```
